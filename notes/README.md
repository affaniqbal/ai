# Notes

Your personal repository of notes and documents. These files are the source of truth.

- **Add a note:** make a new `.md` file here (or copy `_template.md`). Markdown is plain text.
- **Add a document:** drop a `.pdf` into this folder.
- **Publish:** double-click **Publish Notes** on your Desktop. The site updates in about a minute.

Front-matter (the part between `---` lines) is optional: `title`, `date` (YYYY-MM-DD), `tags: [a, b]`.
Without it, the first `# heading` is used as the title. Files starting with `_`, and this README, are ignored.
