How Markdown works

A few basics — that's really all you need:

  • # Heading makes a big heading, ## Heading a smaller one.
  • **bold** gives bold, *italic* gives italic.
  • Start a line with - to make a bullet.
  • [link text](https://example.com) makes a link.

Everything is a plain file on disk, so it's yours to move anywhere.
